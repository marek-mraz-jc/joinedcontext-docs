# Make a dashboard

A dashboard shows the project's data on a map and in widgets, page by page. This page creates the smallest one: one page with one layer. It is for data stewards and analysts.

## 1. Fill the dashboard form

Open **Dashboards** and click **New dashboard**. Give it a **Name** and a **Title**. Add a page under **Pages** and tick the **Layers** it shows. Propose it with **Propose change**; it opens for its readers once approved.
