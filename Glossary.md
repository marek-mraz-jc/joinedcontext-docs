# Canonical Glossary

This glossary defines the normative vocabulary of the joinedcontext platform. Each term is stated with its precise definition and owning architectural specification. Deprecated terms from the legacy CIVITAS/CORE v2 platform are explicitly marked with `(legacy)` alongside their direct replacements.

## 1. Terms and Definitions

- **Access Surface** — the endpoint and space child path `/access` exposing caller effective grants as AuthZEN permissions, ODRL 2.2, or UCAST AST, specified in [Architecture/04-context-spaces-and-endpoints.md#1b-access-surface-of-an-endpoint-access](Architecture/04-context-spaces-and-endpoints.md#1b-access-surface-of-an-endpoint-access).
- **Addon** — a modular, pluggable external workload (such as Grafana, Superset, or Agent Runner) that consumes data exclusively through Endpoints, defined in [Deployment/04-components-and-addons.md](Deployment/04-components-and-addons.md).
- **Agent access** — the optional `access` block of an `AgentProfile` manifest specifying exact operations, kinds, verbs, and endpoints an agent may reach, intersected with the initiating user's permissions at runtime (AG-70, MF-40), specified in [Architecture/07-agents-and-mcp.md#8-what-an-agent-may-reach](Architecture/07-agents-and-mcp.md#8-what-an-agent-may-reach).
- **App (on demand)** — a lightweight, purpose-built application (static kit specification or fullstack code) generated by an AI agent from confirmed `dataNeeds` and served behind the edge login, specified in [Architecture/16-apps-on-demand.md](Architecture/16-apps-on-demand.md).
- **Application (legacy)** — deprecated CIVITAS/CORE v2 term for specialized external tools, superseded by [Addon](Deployment/04-components-and-addons.md).
- **Artifact Store** — an S3-compatible immutable object store (RustFS by default) persisting pre-rendered schemas, compiled mappings, and export bundles, specified in [Architecture/17-artifact-store.md](Architecture/17-artifact-store.md).
- **Builder agent** — the `builder` profile of the Agent Runner: coding tools in an ephemeral workspace plus allow-listed internet egress, building, testing and repairing Apps on Demand without a person, specified in [Architecture/16-apps-on-demand.md](Architecture/16-apps-on-demand.md).
- **Blueprint Instance** — a concrete parameter instantiation of a versioned Blueprint, rendered into manifests by the reconciler; what the Portal shows as a Flow. Specified in [Architecture/06-configuration-as-code.md](Architecture/06-configuration-as-code.md).
- **Blueprint** — a parameterized, versioned Minijinja template that expands deterministically into concrete platform manifests, specified in [Architecture/06-configuration-as-code.md](Architecture/06-configuration-as-code.md).
- **City Repository (legacy)** — deprecated early draft term for an Organization's declarative Git repository, superseded by [Org Repository](Architecture/06-configuration-as-code.md).
- **City-as-Code (legacy)** — deprecated early draft term for the declarative configuration plane, superseded by [Configuration as Code](Architecture/06-configuration-as-code.md).
- **cityctl (legacy)** — deprecated CLI binary name, superseded by [jcctl](Architecture/06-configuration-as-code.md#3-the-jcctl-reconciler-engine).
- **Configuration as Code (CaC)** — the operational paradigm where Git is the sole source of truth and live state is converged by reconcilers, specified in [Architecture/06-configuration-as-code.md](Architecture/06-configuration-as-code.md).
- **Context Broker** — an ETSI GS CIM 009 NGSI-LD compliant broker (default: Antares in Rust) managing entity state and subscriptions, specified in [Architecture/01-overview.md](Architecture/01-overview.md).
- **Context Gateway** — the high-performance Rust reverse proxy executing Policy Enforcement Point (PEP) duties, query AST rewriting, and representation translation, specified in [Architecture/05-context-gateway.md](Architecture/05-context-gateway.md).
- **Context Space** — an isolated data partition mapped 1:1 to an NGSI-LD broker tenant and owned by exactly one Project, specified in [Architecture/03-domain-model.md#context-space](Architecture/03-domain-model.md#context-space).
- **Conversation** — an interactive agent run (`kind: conversation`) started from the Portal assistant panel or API without an application target, answering questions in prose or via registry operations, and capable of being resumed or continued across sessions (AG-67, AG-68), specified in [Architecture/09-portal.md#11-the-assistant-workbench](Architecture/09-portal.md#11-the-assistant-workbench).
- **Derived pipeline** — a Pipeline whose source is a Context Space (query or subscription) and whose compute step (Bloblang, Mapping, Rust WASM module or container Job) writes results back into the same or another space with `derivedFrom`/`computedBy` provenance, specified in [Architecture/08-pipelines.md](Architecture/08-pipelines.md).
- **Dashboard** — a declarative manifest (`kind: Dashboard`) organizing map and analytics pages bound to Endpoints, rendered natively in the Portal UI or routed to an addon, specified in [Architecture/10-dashboards-and-visualization.md](Architecture/10-dashboards-and-visualization.md).
- **Data Model** — an authoritative domain schema authored in LinkML and compiled into JSON Schema draft-07 and JSON-LD `@context`, specified in [Architecture/11-data-models.md](Architecture/11-data-models.md).
- **DataPool (legacy)** — deprecated CIVITAS/CORE v2 term for administrative domains, superseded by [Project](Architecture/03-domain-model.md#project).
- **DataSet (legacy)** — deprecated CIVITAS/CORE v2 term conflating storage, schema, and API distribution, superseded by the decoupled triad of Context Space, Data Model, and Endpoint, specified in [Architecture/03-domain-model.md](Architecture/03-domain-model.md).
- **Connector / ETL job (legacy)** — deprecated CIVITAS/CORE v2 term for a whole ingestion job, superseded by [Pipeline](Architecture/08-pipelines.md). The v2 platform called it a DataSource; this specification uses that name for the connection alone.
- **DataSource** — manifest kind holding the connection of one external feed (`mqtt`, `http`, `websocket`, `gtfs-rt`) and its `secretRef` credentials, rendered into the Bento input of every [Pipeline](Architecture/08-pipelines.md) that references it (MF-35, PL-39).
- **DataSpace (legacy)** — deprecated CIVITAS/CORE v2 term for a collaborative working domain, superseded by [Project](Architecture/03-domain-model.md#project); the Dataspace Protocol connector is a different concept, specified in [Architecture/18-data-space-connector.md](Architecture/18-data-space-connector.md).
- **DataStructure (legacy)** — deprecated CIVITAS/CORE v2 term for schemas, superseded by [Data Model](Architecture/11-data-models.md).
- **Distribution (legacy)** — deprecated CIVITAS/CORE v2 term for static data copies, superseded by [Endpoint Representation](Architecture/04-context-spaces-and-endpoints.md#4-multi-representation-translation-engine).
- **Endpoint** — a policy-bound, multi-representation data view over a Context Space exposed through an opaque random base32 slug, specified in [Architecture/04-context-spaces-and-endpoints.md#3-the-endpoint-model](Architecture/04-context-spaces-and-endpoints.md#3-the-endpoint-model).
- **Endpoint Representation** — an on-demand projection (NGSI-LD, GeoJSON, CSV, XLSX, OGC Features, STA, MCP) served dynamically by an Endpoint, specified in [Architecture/04-context-spaces-and-endpoints.md#4-multi-representation-translation-engine](Architecture/04-context-spaces-and-endpoints.md#4-multi-representation-translation-engine).
- **Evidencia** — the local context space segment in legacy URNs and ADR 001, preserved in the platform URN scheme, specified in [Architecture/03-domain-model.md#3-identity-and-urn-specification](Architecture/03-domain-model.md#3-identity-and-urn-specification).
- **Flow** — one instantiation of a Blueprint with its parameters filled, managed in the Portal's flow gallery (the application's primary model, CC-30) and carrying the CC-33 lifecycle; the manifests it expands to are the record. Not a Pipeline: a Pipeline is one of the resources a Flow may produce, and can be created on its own in the expert view. Specified in [Architecture/06-configuration-as-code.md](Architecture/06-configuration-as-code.md).
- **Foreign Data Model** — a read-only mirror of a peer endpoint's schema committed when referencing external spaces, specified in [Architecture/11-data-models.md#75-mappings-across-context-spaces-and-instances-federation](Architecture/11-data-models.md#75-mappings-across-context-spaces-and-instances-federation).
- **Interaction Lanes** — risk-classified change channels (Green self-service, Yellow domain approval, Red multi-stakeholder governance), specified in [Architecture/06-configuration-as-code.md#4-risk-classified-interaction-lanes-cc-63cc-66](Architecture/06-configuration-as-code.md#4-risk-classified-interaction-lanes-cc-63cc-66).
- **`jcctl`** — the unified Rust CLI and daemon reconciling Git manifests to cluster infrastructure and live services, specified in [Architecture/06-configuration-as-code.md#3-the-jcctl-reconciler-engine](Architecture/06-configuration-as-code.md#3-the-jcctl-reconciler-engine).
- **Layer** — a declarative visual styling manifest (`kind: Layer`) binding an Endpoint's GeoJSON representation to MapLibre GL JS or deck.gl map renderers, specified in [Architecture/10-dashboards-and-visualization.md](Architecture/10-dashboards-and-visualization.md).
- **Mapping** — a schema-aware model-to-model transformation declared in LinkML-Map and compiled to Bloblang or gateway IR, specified in [Architecture/11-data-models.md#7-mappings-with-linkml-map](Architecture/11-data-models.md#7-mappings-with-linkml-map).
- **Model Context Protocol (MCP) Façade** — Streamable HTTP interfaces exposing data queries and configuration tools to autonomous AI agents, specified in [Architecture/07-agents-and-mcp.md](Architecture/07-agents-and-mcp.md).
- **edge login** — the APISIX `openid-connect` plugin in session mode in front of the Portal (`portal.{domain}`) and of every App on Demand route, one confidential client `edge` per realm; it hands the upstream `X-Userinfo` and `X-Access-Token`. Replaced the oauth2-proxy sidecar of ADR-N-017 ([ADR-N-019](Decisions/adr-n-019-login-at-the-edge-apisix-openid-connect.md)).
- **Org Repository (`org-repo`)** — the single Git repository holding an Organization's declarative state, reconciled by `jcctl`, specified in [Architecture/06-configuration-as-code.md](Architecture/06-configuration-as-code.md).
- **Mandant (legacy)** — the German legacy name of the top-level administrative boundary, superseded by [Organization](Architecture/03-domain-model.md#organization).
- **Organization** — the highest-level administrative tenant boundary owning user accounts, projects, and a single Git repository, specified in [Architecture/03-domain-model.md#organization](Architecture/03-domain-model.md#organization).
- **Pipeline** — one running Bento data integration, a resident stream or a scheduled CronJob, that reads a Data Source and writes into a Context Space through an Endpoint. Not a Flow: a Flow is a filled-in Blueprint that may produce a Pipeline among other resources. Specified in [Architecture/08-pipelines.md](Architecture/08-pipelines.md).
- **Policy Entity** — an NGSI-LD entity (`type: Policy`) declaring granular access control constraints evaluated by the gateway PDP, specified in [Architecture/05-context-gateway.md](Architecture/05-context-gateway.md).
- **Portal** — the administrative interface, one Rust application that serves the embedded React UI, the APIs and the in-process reconciler, specified in [Architecture/09-portal.md](Architecture/09-portal.md).
- **Project** — a departmental collaborative workspace within an Organization grouping Context Spaces, Pipelines, and Dashboards, specified in [Architecture/03-domain-model.md#project](Architecture/03-domain-model.md#project).
- **Razidlo** — the issuer segment in legacy URNs, modernized to the Organization's verified internet domain, specified in [Architecture/03-domain-model.md#3-identity-and-urn-specification](Architecture/03-domain-model.md#3-identity-and-urn-specification).
- **Reconciler** — the reconciliation engine within `jcctl` executing plan and apply sync waves, specified in [Architecture/06-configuration-as-code.md#3-the-jcctl-reconciler-engine](Architecture/06-configuration-as-code.md#3-the-jcctl-reconciler-engine).
- **Schema Surface** — the `/schema/` child path of spaces and endpoints publishing models in LinkML, JSON Schema, context, SHACL, OWL, and RDF, specified in [Architecture/04-context-spaces-and-endpoints.md#1a-schema-surface-of-an-endpoint-schema](Architecture/04-context-spaces-and-endpoints.md#1a-schema-surface-of-an-endpoint-schema).
- **ScopeDefinition** — an NGSI-LD entity defining a node in the platform's hierarchical three-rooted scope taxonomy (`/geo`, `/domain`, `/admin`), specified in [Architecture/03-domain-model.md#4-scope-hierarchy-taxonomy](Architecture/03-domain-model.md#4-scope-hierarchy-taxonomy).
- **ServiceAccount** — a Kubernetes-style resource declaring identities, scoped roles, and credentials for non-human clients, specified in [Architecture/12-identity-and-access.md#3-service-identities](Architecture/12-identity-and-access.md#3-service-identities).
- **SyncSource** — a declarative resource defining continuous synchronization from external Git repositories, bundle URLs, or remote instances, specified in [Architecture/06-configuration-as-code.md#sync-mf-27mf-32](Architecture/06-configuration-as-code.md#sync-mf-27mf-32).
- **Tenant (legacy)** — ambiguous legacy term, separated into Organization at the administrative level and NGSI-LD broker tenant at the data level, specified in [Architecture/03-domain-model.md](Architecture/03-domain-model.md).
- **Tenant ID (legacy)** — deprecated platform-level identifier of a broker partition, superseded by [Context Space](Architecture/03-domain-model.md#context-space) and never exposed as a client header.
- **User Application (legacy)** — deprecated CIVITAS/CORE v2 term for the web front end, superseded by [Portal](Architecture/09-portal.md).
- **URN Scheme** — the deterministic platform entity naming convention `urn:ngsi-ld:{Type}:{orgDomain}:{space}:{localId}`, specified in [Architecture/03-domain-model.md#3-identity-and-urn-specification](Architecture/03-domain-model.md#3-identity-and-urn-specification).
- **Work run** — an autonomous agent run (`kind: application`, `dashboard`, or `analysis`) executing unattended operational tasks without interview prompts, concluding with preview generation, manifest proposals, or analysis reports under risk-lane governance (AG-69), specified in [Architecture/19-agent-runner.md#10-conversations-and-unattended-work](Architecture/19-agent-runner.md#10-conversations-and-unattended-work).

- **Data Space Connector** — addon behind the Endpoint layer implementing the Dataspace Protocol and DCP; negotiates ODRL agreements that compile into `Policy` entities and agreement-bound Endpoint tokens, specified in [Architecture/18-data-space-connector.md](Architecture/18-data-space-connector.md).
- **DataAgreement** — manifest whose status records a negotiated contract; on the provider side it yields `Policy` entities, on the consumer side a transfer token reference used by registrations, mounted endpoints and pipelines (DS-09…DS-19).
