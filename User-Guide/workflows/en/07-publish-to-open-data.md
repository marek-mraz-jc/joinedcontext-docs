# Publish to an open-data catalogue

The **Open data** page lists the project's CKAN catalogues and the endpoints published to them. From there you register a catalogue and publish an endpoint as a dataset. It is for data stewards and open-data officers.

## 1. Open the Open data page

Open **Open data**. **Catalogues** lists each catalogue the project publishes to. To register a new one, fill its **Name** and **URL**, and in **API token secret** name the secret that holds the token, never the token itself, then click **Propose catalogue**.

![The Open-data catalogue page with its catalogues and published endpoints](../../img/en/ckan-1-open-data-page.png)

## 2. Publish a dataset

Click **Publish a dataset** and pick the **Endpoint**. **Draft the description** drafts the dataset's description from the model and the organization; **Preview the entry** shows it as CKAN will. Propose it, and it is published after approval.

## 3. Check it is listed

**Published endpoints** shows each endpoint with its dataset and the catalogue it went to. A link opens the dataset in CKAN.

![The published endpoints, each with its dataset and catalogue](../../img/en/ckan-2-published-endpoints.png)
